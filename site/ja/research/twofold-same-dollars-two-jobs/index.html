同じドルを二度働かせるDeFi――TwofoldとDualPool型資本再利用

Research as of: 2026-08-31Updated: 2026-08-31Risk level: HighPublication ID: scmr-20260831-002

要約

TwofoldはRobinhood Chain上でUniswap v4のDualPool hookを利用し、LP資本のUSDG側を、取引がない時間はMorpho系vaultへ置き、swapが来た瞬間だけ流動性として引き出す構造を実装している。従来「lendingに置くか、LPに置くか」の二者択一だった資本を、同時ではなく時間軸で切り替え、borrower interestとswap feeの双方へ接続する。

2026-08-31時点では、現行Twofold docsがRobinhood Chain（chain id 4663）のDualPoolHook、Factory、Registry、StakingVault、TWO token等のcontract addressを公開し、Registryに19 listingsがあると明記している。TWO token contractにも実トランザクションが確認できる。したがって、初稿で懸念した「未deployかもしれない」という問題は、旧stats.htmlがlaunch前文言のまま残っていることによるsite-level inconsistencyと見るのが妥当である。

ただし、公開時点で確認できるのは「contracts / Registry / deposits open」というdeployment evidenceまでであり、Twofold固有のaggregate pool TVL、Twofold poolだけのswap volume、realized LP fee、harvest実績は別問題である。現行docs自身が「まだharvestは一度も行われず、protocol revenueは0」と明記している。よって本稿は高利回り実績の紹介ではなく、資本再利用primitiveの初期deployment研究として読むべきである。

1. 同じ資本を、時間で二つの市場へ接続する

DualPool型の資本サイクルは単純である。

LP資本は平時にallowlistされたERC-4626 vaultへ置かれる。swapが発生すると、hookが必要な資本を同一transaction内で引き出し、Uniswap v4上でswapを成立させ、feeを得た後、残余資本をvaultへ戻す。

「同じドルを二重計上する」のではない。同じ元本が時間によって役割を切り替える。

  • idle時：lending / vault yield
  • swap時：LP fee
  • swap後：vaultへ戻る

この違いは重要である。Tomb型のように新token emissionを主原資としてAPRを作るのではなく、設計上の収益源は外部のborrow interestとtrading feeである。

2. Deploymentは確認できた。ただし旧ページが残っている

現行docsはchain id 4663上の主要contractを以下のように公開している。

  • DualPoolHook: 0x127B3f3b7769f659C5eDBfF8b4005443f19FAAc0
  • AllowlistedFactory: 0x92cbCe5d1f5b7018b98bE81a8B9d010B547F0c85
  • OperatorController: 0xc7295643EC5414DE243e3F9810Eb28F85e5d9ABb
  • VaultAllowlist: 0xe44C0d41A1aFbF7234492bb7a3F745246c351C42
  • Registry: 0x1b66DD14C9281A18E696dbdb40cFB5070842c0C2
  • StakingVault: 0x06E463fDa4BEb4aA096142E673240aB9719fB3A9
  • TWO token: 0x2A4a33A2163D005d8E7f1D9aC08d14c98db288d5
  • underlying Steakhouse USDG vault: 0xBeEff033F34C046626B8D0A041844C5d1A5409dd

現行docsは19 pools/listings、deposits openを明記する。TWO contractはexplorerでverified contractとして表示され、多数のtransaction / Transfer / Approval eventsが存在する。

一方、stats.htmlには依然として「contracts are not yet deployed」というlaunch前文言が残る。ここは隠すべきではない。現行docs・appと旧stats pageの更新状態が一致していないため、読者はWeb UIの一画面だけからdeploymentを判断すべきではない。

本稿では、現行contract registryとexplorer evidenceを優先する。

3. Pool TVLとfee実績は、まだ同じ強さでは確認できない

Twofoldの現行home/appは19 poolsをRegistryから読むと説明し、各poolが0.30% swap feeを設定しているとする。一方、表示される「pair volume, 24h」はTwofold固有poolのvolumeではなく、Robinhood Chain上の全Uniswap v4 poolにおける当該pair volumeだとdocs自身が注意している。

したがって、その数字をTwofoldのfee実績へ直接掛け算してはいけない。

さらに、旧Statsのaggregate Pool TVL欄は空のままであり、今回のResearch ReviewではTwofold固有aggregate TVLを独立に固定できなかった。第三者が示すTWO tokenのliquidityやvolumeも、DualPool LPのTVLとは別物である。

事実として固定できるのは次までである。

  • contractsが公開されている。
  • Registry listingsが19あると現行docs/appが読む。
  • deposits openと明記されている。
  • underlyingのSteakhouse USDG vaultはMorpho上で実在し、大型資本を保有する。
  • Twofold固有aggregate Pool TVL / realized swap fee / harvest revenueは、今回独立に固定できていない。

4. TWOのrevenue routingは「実収益が既に出ている」とは言えない

TwofoldはTWOをfixed 1B supply、no mint、no ownerと説明し、StakingVault経由でprotocol revenueをUSDG + USDC等のreal assetsとして配る設計を掲げている。

しかし、現行docsは同時に重要な留保を書いている。

pools are live, but no harvest has happened and the protocol has earned nothing from them.

将来harvestが起きた場合、protocolはpool profit（vault yield + trading fees above basis）の最大20%を受け取れる。LP principalは対象外とされる。

したがって現時点で、「TWO stakingはprotocolの実収益を継続配当している」と表現するのは早い。staking UIやlaunch-funded rewardsと、realized protocol harvest revenueを分けなければならない。

5. Audit / contract risk

DualPool hookについて、TwofoldはUniswapがauditしたupstream bytecodeをbyte-for-byte unmodifiedでdeployしたと説明する。一方、Twofold固有wrapper contractsはopen sourceで、Slither、Aderyn、Halmos、Mythril等によるstatic/formal/mutation testingを実施したとするが、第三者audit済みとは確認できない。

したがってriskは二層に分ける。

  1. upstream DualPool core risk
  2. Twofold wrapper / Registry / Controller / VaultAllowlist / StakingVault等のproject-specific risk

「Uniswapがauditした」ことをTwofold全体のaudit済みと読み替えない。

6. Capital parkingの次に何が生えるか

Twofoldが面白いのは単独protocolとしてより、Robinhood Chainの資本形成の第二段階としてである。

2026-08-31取得のMorpho Robinhood Chain dataではtotal deposits約9.21億ドル、active loans約4.08億ドル、TVL約5.12億ドル。stablecoinとlending layerが先に厚くなり、その既存vaultを部品としてcapital-reuse primitiveが生える。

これは、

new chain → stablecoin inflow → lending layer → vault capital base → capital-reuse primitive

というComposition Boomの一例になり得る。

前提・限界・反証条件

  • DualPoolHook等のcontract addressは現行docsで固定したが、wrapper群の個別deployment block/dateを今回の公開Evidence packageでは独立に固定できていない。TWO tokenについては2026-08-28 launchの第三者on-chain market indexがある。
  • Twofold固有aggregate pool TVL、Twofold poolだけのswap volume、realized fee、harvest countは独立に固定できていない。
  • docs掲載のpair-volumeはchain上全Uniswap v4 poolのpair volumeであり、Twofold revenueではない。
  • 現行docsによればprotocol harvest revenueはまだ0。将来のfee-routing設計と実績を混同しない。
  • wrapper contractsについて第三者auditを確認できていない。
  • lending yield + swap feeの追加収益が、smart-contract、LP、depeg、market-hours等の追加riskを上回るとは限らない。
  • 今後on-chain aggregate TVL / realized harvest dataが公開され、docsの説明と一致しなければ本稿の評価を改訂する。

Clearstar cbAssets、Morpho側で2% Merkl報酬の29日継続表示を確認

Base上のMorpho Clearstar cbAssets V2について、2026-09-04 03:31 JSTの前回観測では後続インセンティブを独立確認できなかったが、今回のMorpho OpportunitiesはAPR 6.1%（2% Merklを含む）、TVL 3,021万ドル、日次報酬1,660ドル、残り29日と表示した。Merkl legacy画面は総APR 6.07%（protocol 4.07% + Merkl 2%）、TVL 3,017万ドルを表示する一方、1 active / 0 upcomingのままである。2%の外部報酬が直ちに終了するとの見方は弱まったが、キャンペーンの見え方には提供元間の差が残る。

何が変わったか

前回2026-09-04 03:31 JSTは、Merkl legacyが1 active / 0 upcomingを示し、Morpho一覧でも独立した後続campaignを確認できなかったため、2026-09-05以降の2%報酬継続を確認不能としていた。今回、Morpho Opportunitiesは同vaultに2% Merklを含むAPR 6.1%と『29d left』を明示した。TVLは約3,000万ドルで大きくは変わっておらず、主な変化は利回り水準ではなくインセンティブ継続期間の可視性である。

なぜ重要か

Clearstar cbAssetsの表示利回りはMorpho側のprotocol yield約4.1%にMerklの2% USDC報酬を重ねた構造で、外部報酬はheadline APRのおよそ3分の1を占める。Morpho側で29日継続が表示されたことは短期的な利回り持続性の判断材料になる一方、Merkl legacyでは後続campaignが別項目として表示されていないため、単一UIだけで期間を確定すべきではない。

留保

Morpho Opportunitiesは29d leftを表示する一方、Merkl legacyは1 active / 0 upcomingのままで、同legacy画面のactive campaign欄には2026-09-05終了の日付表示も残る。Merkl legacyの取得面には更新遅延またはUI/cache差が含まれる可能性があり、後続campaignの個別ID・開始時刻を同画面から独立確認できていない。TVLもMorpho約3,021万ドル、Merkl約3,017万ドルとわずかに異なる。Morpho smart contract、curator/allocation、tokenized-stock collateralのissuer/custody、transfer/redemption、oracle、清算流動性などのriskは別途残る。

市場観測

Aerodrome NVDAc/USDC、表示APYが5,084%へ跳ねる一方でデータ乖離が拡大

Base上のAerodrome Slipstream USDC-NVDAcについて、DeFi Terminalの個別poolページが観測時点で総APY 5,084.39%（base 146.47% + reward 4,937.91%）、TVL約170万ドルを表示した。headline APYの約97%がreward成分である。一方、Yieldexは同poolをAPY 521.57%、TVL 138万ドルとしており、DefiLlama系の別取得面も300%台を示す。したがって5,084%を持続的・実現可能な利回りとして確定することはできず、現在の主要な観測事実はreward表示の急拡大とデータ提供面間の乖離である。

市場観測

Clearstar cbAssets、後続インセンティブが現在の取得面では確認できず

Base上のMorpho Clearstar cbAssets V2について、前回観測でMerklの新UIに表示されていた48,758 USDCの後続キャンペーンは、今回取得できたMerkl legacy画面では確認できず、同画面は『1 active / 0 upcoming』を表示している。現行の2% USDC報酬自体は継続しており、Merkl legacyは総APR 5.91%、protocol APR 3.91%、Merkl APR 2%、TVL約3,161万ドルを表示。Morphoのcampaign一覧は総APR 5.92%、うち2% Merkl、TVL約3,038万ドルを表示している。後続報酬が取り消されたと断定はできず、provider/UI間の更新差として扱う必要がある。

市場観測

Bitwise Mag7Xの自動トークン株ポートフォリオに10% APRのUSDC incentive

Base上でBitwise設計・Glider実行のMag7X Automated Token Portfolioが稼働し、Merklは10% APRのUSDC incentiveと約50.8万ドルの対象TVLを表示している。これは単一株vaultやLPではなく、tokenized stockを自己管理ウォレット内で自動リバランスするstructured portfolioに外部rewardを重ねた構成である。

市場観測

MAG7、Base上の株式トークンbasketをAerodrome LPとAERO emissionsへ接続

ReserveのMAG7は、Coinbase Tokenized Stocksをbasket化したBase上のDTFをMAG7/USDCとしてAerodrome Slipstreamへ接続し、AERO emissionsを受ける構成を稼働させている。今回のMarket Watchで未捕捉だったcompositionとして新規確認した。GeckoTerminalの観測値は流動性約43.48万ドル、24時間出来高約3.13万ドル、42 transactions、58 holders。MAG7自体にはBase/Merkl提供の最大2% cashbackも案内されているが、LP参加者が同じcashbackを受け取れるかは確認できていない。

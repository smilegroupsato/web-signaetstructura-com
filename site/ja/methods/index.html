Methods

観測、再構築、反証可能性。

数値、Evidence、Historical Replay、SNS・オンチェーン分析をどのように扱うかを公開します。

Evidence

一次情報を優先し、重要主張には取得日時と出典を紐付けます。事実、推測、意見、将来予測を区別します。

Historical Replay

replay_date時点で取得可能だった情報だけを用い、未来の値動きを判定後に開封します。成功例だけでなくfalse positive / false negativeも記録します。

Figures

Data Figureは可能な限り元dataとfigure specを保持し、SVG / PNGを再生成可能にします。observed / reconstructed / estimated / interpolated / unavailableを区別します。

Limitations

欠測、provider差、流動性不足、取得不能データ、推定値は明示します。
